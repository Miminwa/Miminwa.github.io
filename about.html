Quick facts

Location: Asaba, Nigeria
Role: Security Engineer
Education: B.Sc Physics (1st Class)
IELTS: 7.0 (C1)
Languages: English, Igbo, German (A1)

I'm Miracle Chimamanda Ndubuisi - an Offensive Security Engineer with hands-on experience in penetration testing, red team operations, SIEM monitoring, and incident response across mobile, web, API, and cloud infrastructure.

My daily work involves breaking into systems (with permission) - performing mobile application pentesting on Android and iOS, executing red-team operations mapped to MITRE ATT&CK, hunting for vulnerabilities across fintech platforms, and building real-time alerting dashboards. I'm increasingly focused on the intersection of offensive security and artificial intelligence - how AI systems can be attacked, how they change the threat landscape, and how offensive techniques can be automated with machine learning.

What makes me different: I don't just find vulnerabilities - I study them. With 3 publications (including one under review at Springer), I bridge the gap between frontline security engineering and academic research. I'm currently seeking a PhD to explore AI security and offensive security research, building on real-world experience breaking into production systems.

My path into security is unconventional - a First-Class Honours degree in Physics with a thesis on AI awareness, teaching experience that sharpened my ability to communicate complex ideas clearly, and a relentless curiosity that led me from the physics lab to the security operations centre.

Research interests

Automating penetration testing and vulnerability discovery with AI/ML
Security risks in mobile and web apps that integrate AI features
How large language models can be exploited or misused in security contexts
Using machine learning to improve threat detection and intrusion detection
